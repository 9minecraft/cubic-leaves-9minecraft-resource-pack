# Cubic Leaves — Bushy 3D Foliage for Vanilla Trees

Cubic Leaves 9minecraft Resource Pack replaces vanilla flat tree foliage with dense, bushy cubic leaf blocks. Every tree gets fuller shapes with extra cubic layers that spill past the block edges. Forests and orchards look much greener and thicker while keeping the original pixel art feel. The pack works instantly in pure vanilla without slowing down your game.

Turns standard flat leaf textures into layered 3D cubic tree foliage.

## What this build is

An unofficial rebuild of **zanderest**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
